# FE-PINC code and data

Numerical code and research inputs for **Tracing rheological parameter
compensation in tunnel back-analysis using physics-informed neural
continuation**, Pengcheng Zhu and Tielin Chen, prepared for *Engineering Geology*.

This compact release includes the FE, constitutive and neural implementations,
digitized laboratory and field observations, numerical reference contour and
construction inputs. Predictions, fitted-result tables, local training tensors,
trained weights, figures and computational caches are generated by running the
code and are omitted from the archive. The two small starting vectors in the
field configuration are inputs to the construction calculation.

## Install

Use Python 3.13 and install `requirements.txt` in a virtual environment:

```console
python -m pip install -r requirements.txt
```

All supplied commands support CPU execution. Run them from this directory.
The material and derivative runtime is included; no sibling project, archived
report, CAD program or original DXF is required.

## Data and units

| Input | Meaning |
|---|---|
| `data/field/935.json` | 91 original graphical readings over 49.0 days, model geometry, weights and dated construction |
| `data/field/915.json` | 80 independent graphical readings over 45.1 days, with the same geometry and material anchors |
| `data/field/*.csv` | Original digitized field-chart coordinates (source report 290, Figures 20 and 22) |
| `data/field/construction.json` | Calendar intervals, author-confirmed 6 m upper bench, support inputs and their source notes |
| `data/field/config.json` | Bounds, two initialization vectors and solver/training settings |
| `data/laboratory/fig16338.csv`, `fig16343.csv`, `fig16348.csv` | Staged axial-creep curves at bedding angles 0, 30 and 90 degrees |
| `data/laboratory/fig16335.csv`, `fig16340.csv`, `fig16345.csv` | Corresponding axial stress–strain curves for loading secants |
| `data/geometry/tangent_arcs.json` | Metre-based tangent-arc reference contour with inner and outer support outlines |
| `data/synthetic.json` | Synthetic generating parameters, observation/time grids, bounds and preparation/training settings |

The slate data are digitized median-specimen curves from source report 272,
Section 3.3 (50 × 50 × 100 mm specimens, intermediate/minor stresses 10/5 MPa).
The CSV `series` labels identify stress levels; creep `x` is within-stage hours
and `y` is cumulative strain in percent. For stress–strain CSVs, `x` is strain
percent and `y` is axial stress in MPa. The fitting code excludes the compressed
loading-rise prefixes and terminal failure stages, giving 42, 24 and 19 usable
observations. These are digitized research inputs, not instrument time-series
exports. The historical lab-fit module's note about an unrecovered minor
stress refers to its original table extraction; the manuscript uses the
subsequently verified 5 MPa confinement.

Field JSON stamps preserve fractional graphical abscissae in day-of-year units;
their fractions do not establish observed hours. Displacements are mm,
construction intervals and rheological times are days, geometry is metres,
and stress/modulus anchors are MPa. Each channel retains its own first-reading
mechanical datum and has one fitted constant offset. The CAD contour is the
author-approved reference shape, not a surveyed shaft as-built section.

## Run the field model and regenerate FE-PINC results

```console
python run_construction.py data/field/935.json --output output/forward935.json --jacobian
python run_field_pinc.py profiles --workers 2
python run_field_pinc.py train
python run_field_pinc.py queries --workers 2
```

The three FE-PINC stages generate the fixed-Maxwell-time centers, train the
labelled maps using seeds 11/29/47, and apply fresh nonlinear FE corrections
to the off-grid predictions. Results go to `output/field`; `all` runs these
stages in order. These calculations can take substantial time because profile
construction and correction solve the full history-dependent FE problem.

The release's `primary` setting is the current 6 m dated-construction model.
`--variant soft_support`, `stiff_support`, `no_casting` and `half_step` select
the stated model sensitivities. Each variant writes to its own directory.
Remove the relevant generated output directory before rerunning with changed
inputs, since existing stage results are reused. The original FE-PINC producer
is retained in `run_field_pinc.py`; `field_workflow.py` replaces only its
project-specific input/output discovery and progress recording.

To evaluate section 915 conditionally, copy the fitted `theta` from the 935
result into a copy of `data/field/915.json`, then run `run_construction.py` on
that file. The four datum constants are profiled on the supplied observations;
the rock-mass parameters are transferred unchanged.

## Regenerate laboratory fits and synthetic observations

```console
python run_laboratory.py
python run_synthetic.py --jacobian
```

The laboratory command first rebuilds the preliminary fits from the six input
CSVs, then computes the 25-node Maxwell-viscosity profiles in `output/laboratory`.
The synthetic command generates the noise-free displacement observations and
optional physical-coordinate Jacobian in `output/synthetic.json`.
Synthetic profile sampling settings and seeds are in `data/synthetic.json`;
the numerical APIs below support preparing and training those profiles.

## Method entry points

| Source | Purpose |
|---|---|
| `experiments/fe_pinc/core.py` | Coordinate maps, projected stationarity and fixed-active-set tangents |
| `experiments/fe_pinc/network.py` | Labelled Fourier-feature continuation network |
| `method.py` | Local FE tensors, smooth-profile sample assembly and candidate selection |
| `experiments/geometry_revision/rheo_pinc_network.py` | Separate FE-value and applicable local-physics supervision |
| `experiments/geometry_revision/field_pinc_network.py` | Separate value, quadratic and optional tangent sets |
| `experiments/geometry_revision/trf_solver.py` | Nonlinear FE correction and fresh endpoint evaluation |
| `experiments/geometry_revision/rheo_replay.py` | Committed-state implicit derivatives |
| `experiments/geometry_revision/construction.py` | Staged boundary release and stress-free support installation |
| `runtime/experiments/` | FE, constitutive, geometry, exterior-operator and laboratory dependencies |

`method.local_terms(theta, values, physical_jacobian, problem, coordinate)`
constructs weighted residual gradients, Gauss–Newton matrices and local slopes.
`method.prepare_profile(bundle)` keeps FE-value rows separate from local physics;
the supplied function checks resolved neighborhoods before admitting synthetic
tangent targets. Pass its `arrays` to `rheo_pinc_network.train_continuation`.
The field producer uses local residual linearizations and leaves tangent arrays
empty, as in the manuscript. A local slope at an unresolved material switch is
not silently treated as a smooth stationary-profile derivative.

## Read the predictions

For predictions `a` and `b`, `sqrt(mean((a-b)**2))` is their mutual spread.
For measurements `y`, `sqrt(mean((a-y)**2))` is fitting RMSE. Retain the same
channel order and datum convention. The paper's less-than-0.12 mm spread along
the corrected Maxwell path and approximately 18 mm fitting RMSE measure these
different quantities; the path is conditional on the stated loading, support
and observation history.

Please cite the manuscript when using these research inputs or implementations.
